Description:

Source:

Example
// Calcul du CO2 économisé pour un trajet de 100 km avec une consommation de 6 L/100 km, motorisation essence et 2 occupants

Parameters:
Name Type Description
distanceKm number La distance en kilomètres
consommationL100 number La consommation en litres pour 100 km

    Type
    Error
  • - Si le nombre d'occupants est inférieur à 1
    Type
    Error

- Le CO2 économisé en kg
